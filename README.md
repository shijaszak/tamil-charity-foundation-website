# Tamil Charity Foundation Website

## Project Overview
The Tamil Charity Foundation website is designed to promote charitable activities aimed at supporting children's education and community development. It features a modern and responsive design utilizing Tailwind CSS, offering a visually appealing user experience. The website serves as a platform for sharing impact stories, providing information about the foundation’s activities, and facilitating donations.

## Installation
To set up the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
   
2. Navigate to the project directory:
   ```bash
   cd tamil-charity-foundation
   ```

3. Open `index.html` in your preferred web browser to view the website.

## Usage
Once the project is set up and opened in a browser, you can navigate through various sections using the menu. Key sections include:

- **Home**: Overview of the foundation and its mission.
- **About Us**: Information about the foundation.
- **Donate**: A page to make donations.
- **Contact**: Contact details and a form for inquiries.

## Features
- **Responsive Design**: The website adjusts to different screen sizes for optimal viewing on various devices.
- **Custom Colors**: Uses specific shades aligned with Tamil culture for branding.
- **Impact Stories**: Shares testimonials and stories showcasing the foundation's impact.
- **Multi-language Support**: Allows users to switch between Tamil and English interfaces.
- **WhatsApp Integration**: Quick access to WhatsApp for inquiries.

## Dependencies
The project leverages the following dependencies:
- **Tailwind CSS**: For styling and responsive design.
- **Font Awesome**: For icons.
- **Google Fonts**: For custom typography.

While there is no `package.json` file in the provided content, the dependencies mentioned are linked directly in the HTML file.
